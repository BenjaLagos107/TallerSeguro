Instrucciones

Para conectar tu base de datos:

  1. Abre el archivo supabaseClient.js.
  2. Reemplaza TU_URL_DE_SUPABASE con la URL de tu proyecto.
  3. Reemplaza TU_ANON_KEY con tu clave pública.
  4. Guarda el archivo y el servidor se recargará automáticamente.
